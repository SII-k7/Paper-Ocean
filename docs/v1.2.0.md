# Paper Ocean v1.2.0 · 应用内一键更新

Windows 安装版和 Ubuntu `.deb` / AppImage 支持「关于与更新 → 检查更新 → 一键更新并重启」。应用显示下载进度，校验安装包，保存当前阅读记录和对话，再安装并重启。下载或保存失败会保留应用并允许重试；普通退出不会自动安装。Ubuntu `.deb` 安装需要确认系统授权。

## 首次迁移

v1.1.1 及以前的版本没有内置下载器，需要最后手动安装一次本版本：

- Windows：下载 **`Paper-Ocean-1.2.0-win-x64-Setup.exe`**，退出旧便携版后安装；以后从开始菜单的 Paper Ocean 启动。便携 `.exe` 仍提供，但不支持应用内替换，请优先使用 Setup 安装版。
- Ubuntu：下载 **`Paper-Ocean-1.2.0-linux-amd64.deb`**，运行 `sudo apt install ./Paper-Ocean-1.2.0-linux-amd64.deb`。以后可在应用内更新。
- AppImage：下载本版本 AppImage，赋予执行权限后打开，之后可在应用内更新。
- macOS：当前 DMG 未签名、未公证，仍采用手动更新。

安装版沿用相同的应用标识与资料目录，保留本机论文、问答、阅读位置和坚果云设置。不要删除应用数据目录。

## 发布与验证

更新仅面向 GitHub 正式版本，禁止自动降级；默认不联网下载，用户点击后才检查或更新。发布附件包含 `latest.yml`、`latest-linux.yml`、安装包和校验文件。更新组件检查 SHA-512，CI 同时验证清单版本、附件大小及散列值。

自动测试覆盖重复操作合并、校验失败阻止安装、保存失败、取消授权后重试和平台识别。真实更新组件使用隔离 HTTP 服务验证下载与损坏文件拒绝；安装包测试验证 Windows Setup 与 Ubuntu 安装后的界面和更新模块。这些测试不上传个人数据，不在用户机器上触发模拟安装。
