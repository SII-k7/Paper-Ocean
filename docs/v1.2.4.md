# v1.2.4 · 论文辅助对话

论文预览底部新增可折叠的「辅助对话」，使用 Luna max，并优先采用账号支持的 Fast。展开为小尺寸浮窗，可以覆盖部分论文预览；折叠后仍会继续生成回答。

- 与右侧主对话使用不同的会话、消息、草稿及流式输出状态，可同时提问、分别停止。
- 辅助上下文只绑定当前论文，切换论文后显示该论文自己的辅助历史。
- 历史和草稿自动保存，展开状态会记住。支持 Markdown、公式及论文页码跳转。
- 沿用 v1.2.3 的 HTTP 连接提速修复。辅助回答使用均衡篇幅，模型思考强度仍为 max。

辅助窗口同时处理一个问题；切换论文时，上一论文仍在生成的辅助回答会继续保存，完成后可以向新论文提问。

## 验证

126 项测试及类型检查、构建通过。真实 Luna max Fast 两个独立会话并发完成；隔离 Electron 界面验证了交错输出不串流、折叠继续、独立停止、历史与草稿恢复、旧辅助会话复用、切换论文以及小窗口边界。可用 `node scripts/smoke-auxiliary-chat.mjs` 重跑界面测试（需 Playwright）；测试使用合成 PDF、模拟流事件和独立临时资料库，不调用真实模型。Windows 发布流水线也会运行该测试。

Windows Setup 安装版可通过「关于 → 检查更新 → 一键更新并重启」安装，保留阅读记录。Windows 便携版与 macOS 请手动下载。
