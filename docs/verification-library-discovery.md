# 资料库、PDF 导航与推荐验证

2026-09-07，全部使用隔离资料库；未覆盖实际用户数据。

## 资料库与原件

- 搜索覆盖标题、作者、arXiv ID、摘要，支持阅读状态筛选和最近打开／首次提交日期／标题排序；按 50 篇递增显示。
- 浏览器实测：筛选已读后只显示对应论文，搜索另一份副本可定位，Esc 关闭后焦点回到资料库按钮。服务和标签页重新启动后，“已读”和“阅读中”状态保留。
- 桌面导入的 PDF 托管到资料库，以内容哈希标识独立版本；原文件移动后仍可打开托管副本。原件损坏时，只有完全相同的内容才可重新定位，并保留被修复文件的归档。Web 继续使用不暴露本地路径的文件句柄。
- 测试覆盖移动原件、同名文件变更、不同版本并存、重复打开不重写文件、错误重定位被拒绝、相同内容修复及原始副本保留。原生文件选择器的完整操作仍待桌面验收。
- 保留年、年月、年月日各自精度；没有日期时显示未知。arXiv 明确指定的 vN 会固定下载该版本；通过元数据确定版本时也固定版本后下载。数据库日期和 arXiv 首次／当前版本提交日期不混用。
- Web 资料库取消前 300 篇截断，350 篇保存／重载测试通过；无效记录导致明确失败，不再静默丢弃。Web 单次资料库保存上限提升到 64 MB，超过上限时仍保留页面未保存副本。

arXiv 日期与版本语义依据：[arXiv API 用户手册](https://info.arxiv.org/help/api/user-manual.html)，其中 `published` 为首次提交时间，`updated` 为所取版本的更新时间，`id_list` 可指定版本号。

## PDF 导航

- 全文查找支持大小写、空白、换行断词和常见连字，保留原文本偏移；逐项跨页定位，最多展示 2,000 处结果。命中区域按文本项几何位置估算，不能替代精确字形边界。
- 内嵌目录、命名目标、页内引用链接和常见翻页动作可用；跳转记录保留最近 20 个阅读位置。外部链接沿用应用的 HTTPS 限制，不执行 PDF 脚本。
- 在实际《Attention Is All You Need》PDF 中，“Multi-Head Attention”检出 8 处；跨页和放大后仍定位到匹配行。目录的 Scaled Dot-Product Attention 跳到第 4 页小节标题。
- 直接点击第 2 页的参考文献链接，跳到第 11 页 [13] LSTM 条目；返回前后滚动位置均为 975 px，第二页顶部均为 246.703125 px。使用定位器的测试工具会先滚动再点击，所以该项最终用可见坐标直接点击复核。
- 导航关闭后焦点返回触发按钮。缩放下限降至 25%，适应目录打开后的窄阅读栏；栅格画布限制为 1,600 万像素、单边 8,192 px，以防极长页面在高倍缩放下产生无界位图。
- PDF CMaps、标准字体、ICC、WASM 及 JS 回退文件已打包。普通论文已验证；扫描、旋转、JPX/JBIG2 和复杂 ICC 实例仍待专项验收。查找不包含 OCR。

## 推荐

- 近期进展保留最近三个自然年的主题相关候选；基础工作来自数据库的参考文献关系，不限制在近三年，也保留没有 arXiv 版本、但有 HTTPS 来源的条目。
- OpenAlex 先匹配当前论文，再使用 outgoing citations；Semantic Scholar 使用 references 接口。相似论文服务返回和主题检索均标注各自关系，不能当成引用关系。
- 卡片显示数据源、来源链接、数据库提供的日期精度；去除无标题条目，按 arXiv ID／规范化标题去重，优先保留可直接打开的版本。引用量只是辅助排序，不显示为质量评分。
- 实际公开接口测试：基础工作返回 8 条，包括 1993 年 Penn Treebank、2015 年 Luong attention、2017 年 ConvS2S；近期进展返回 8 条，包括 FlashAttention-3、Attention as an RNN 等。结果是当时数据库返回的候选，不代表全面综述或最新工作的完整覆盖。
- 持久缓存有效期 24 小时；过期缓存立即可读，同时后台更新。最多两项推荐任务并行，同查询合并；失败后保留缓存并避免连续自动重试。手动刷新可重试。
- 页面测试使用上述实际结果中无需 PDF 缩略图下载的 4 条记录。切换近期／基础／近期／基础后，显示“使用缓存”，后台调用日志仍只有每类一次。
- 自动测试覆盖缓存重启复用、过期立即返回、刷新失败保留结果、手动重试、同查询合并、并发上限、引用方向及旧文献保留。

接口依据：[OpenAlex 引用关系过滤说明](https://github.com/ourresearch/openalex-docs/blob/main/api-entities/works/filter-works.md#cited_by)、[当前语义搜索说明](https://help.openalex.org/api/semantic-search/)、[Semantic Scholar API](https://www.semanticscholar.org/product/api)。基础引用关系属于数据库记录，未逐条与所读 PDF 版本重新核对。
