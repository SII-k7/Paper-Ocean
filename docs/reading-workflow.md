# 阅读与笔记工作流

这些功能属于 v1.0.0 源码升级，旧版安装包不包含它们。运行 `npm run web` 使用独立的 `.paper-ocean-dev/` 资料库；桌面版使用 Electron 的应用数据目录。两者不自动同步。

## 从论文开始

本地 PDF 导入后保存原件副本，外部源文件改名或移动不影响已经管理的副本。资料库可搜索标题、作者、摘要和 arXiv ID，按未读／在读／已读过滤。缺失日期显示未知，不用文件修改时间冒充发表时间。

arXiv 的 `v1`、`v2` 等明确版本会保留；无版本链接取得元数据后，尽可能固定到该版本下载。下载卡片显示收到的字节数，知道总大小时显示进度。暂停保留部分文件，重开页面后可继续。服务器支持有效的 Range 与版本校验时复用断点；服务器忽略续传或文件已变时重新下载，避免拼接不同版本。

若资料库提示原件缺失，重新定位到同一份 PDF。内容不符的另一版本不会替换原来的笔记与讨论。

## 搜索标题与自动归档

顶栏输入标题片段，例如 `openvl` 或 `diffusion pol`，即可展开论文联想。本地匹配即时显示，在线检索在停止输入约半秒后触发；支持词序调整和少量拼写错误。用方向键选择、Enter 打开，也可直接点击结果。中文输入法选字时不会提交搜索。arXiv ID 和链接仍可直接打开。

`Ctrl/⌘ K` 聚焦搜索并选中已有内容，清空按钮删除文字并保留焦点，Escape 收起联想。对话框开启时快捷键不会把焦点移到弹窗外。布局、浮层和提示动效遵循系统的“减少动态效果”设置。

在线联想使用 Semantic Scholar，失败时尝试 arXiv；选中结果后查询 arXiv 标识并通过原有下载流程打开。来源服务限流时会尝试 OpenAlex 和 arXiv 备用索引，只接受相同标题及有效的 arXiv 链接。没有 arXiv PDF 的论文提供来源页，可自行下载后导入。在线数据库不保证覆盖全部论文，也不提供中英文标题自动互译。

资料库中至少有一条已保存用户提问的论文会自动归档 PDF；已有讨论在启动时补齐，多论文讨论归档其固定绑定的论文。仅打开论文、未发送的草稿不会触发。Windows 默认目录为 `D:\paper`，下设“运动控制”“动作生成”“VLA”“世界模型”“待分类”。分类依据标题、摘要和已有的前几页文字，规则判断并不总是准确；资料库内可手动指定分类，或切回“自动判断”。手动改分类会移动归档副本，保留阅读原件及对话。

归档使用内容校验与独立副本，不覆盖内容不符的同名文件。目录不可写、原件缺失等问题会显示在资料库的归档状态中；修复后点击“检查并补齐归档”。这只备份 PDF，对话和笔记仍在应用数据目录中。没有 D 盘时可在启动前设置 `PAPER_OCEAN_ARCHIVE_DIR` 指定其他目录；macOS 默认使用用户目录下的 `paper`。Web 版保存到运行本地服务的电脑，同样遵循该设置。

## 保持阅读位置

“阅读”聚焦 PDF，“讨论”并排显示原文与对话，“探索”再展开推荐。调整栏宽、字号、缩放或重新打开时，恢复页内比例锚点与对话段落；正在阅读旧回答时，新输出不会强行滚到底部。

PDF 工具栏提供查找、目录和返回。`Ctrl/⌘ F` 在阅读器中打开文字查找，Enter／Shift+Enter 切换结果。查找依赖 PDF 的文字层，不识别扫描图片里的字。内部链接跳到 PDF 目标页；外部链接仅支持 HTTPS，由系统浏览器打开。

## 让讨论有明确范围

阅读固定使用 GPT-5.6 Luna、max。旧对话保存过的模型选择不会改变后续请求；不再显示模型／思考强度切换入口。“回答深度”控制答案篇幅，与固定的 max 推理设置不同。若当前 Codex 无法提供 Luna max，会在提问区提示并提供“重试连接”；不会改用其他模型。

“当前论文”恢复该论文的独立讨论；“新讨论”创建同一范围的新会话。“多论文”创建或恢复以当前打开论文为集合的讨论。创建后集合固定，关闭或新增标签不会悄悄改变已有讨论；需要另一组论文时，先调整标签再创建讨论。

讨论可改名、切换，草稿、回答深度和模板各自保存。问题导航用于回看长对话，对话搜索用于定位已有内容。旧版无法确认来源的混合历史保留为只读记录，不猜测它属于哪篇论文。

短文通常提供全部提取文字；长文按问题选取相关页和节选，并标出实际提供页数。文字覆盖不等于视觉覆盖：扫描页、复杂表格和公式应结合“页图证据”检查。本轮最多附三页图，来自当前问题指向的活跃论文；尚不支持自动从多篇论文同时寻找图像证据，也不自动 OCR。

回答中的引用可以跨论文跳转，并返回原位置。页码使用 PDF 实际页序，包含封面。AI 回答与数据库推荐均需回到原文核对，不代表已验证事实。

## 保存证据

选取一页中的文字可创建高亮，再把不同论文、不同页的证据追加到同一笔记。笔记支持 Markdown 与公式预览。将 AI 回答转为笔记时会保留原回答关系，便于回查。

Markdown 导出适合继续编辑；ZIP 还包含原文页图和证据坐标 JSON。当前导出体积上限为 128 MB，大型笔记集可分批导出。导出不是完整资料库备份；完整迁移需要在应用关闭后复制整个数据目录，包括原件、索引和资料库文件。

保存失败时，界面保留未保存内容并提供重试；损坏资料库先保留原文件，再尝试恢复最近备份。Web 中两个页面同时修改时，较旧页面不能覆盖新状态：先导出该页面的未保存 JSON，再重新载入并人工合并。目前不自动合并冲突。

## 继续探索与更新

“基础工作”来自 OpenAlex／Semantic Scholar 的参考文献关系，允许较早或没有 arXiv 版本的论文；“近期进展”是近三个自然年的相关候选，不是完整的最新文献清单。卡片提供来源，缓存过期时先显示旧结果并后台更新。网络失败不清空已有结果。

顶栏“关于与更新”显示当前版本。只有点击“检查更新”才查询公开 GitHub Release；失败、没有正式发布或无法比较版本时会说明原因，仍可打开发布页面。更新由你手动下载与安装。
