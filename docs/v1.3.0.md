# v1.3.0 · 阅读工作台

精简阅读工作台，打通选文、独立对话、引用回查和研究笔记。

- 顶部工具按需展开，论文标题回到阅读区，资料库改为可同时操作原文的侧栏。
- 选文明确附加到主对话或辅助对话；发送前可移除，历史中保留摘录与论文来源。
- 保存回答为笔记时保留当前对话和滚动位置，提供查看、撤销及返回原回答。
- 双路回答逐消息更新，输入采用本地草稿缓冲；切换、发送、停止及关闭前补齐保存。
- 修复快速切论文白屏、停止回答和嵌套菜单焦点问题。

Luna max Fast、原有证据预算、两路独立上下文及 PDF 自动归档分类继续保留。157 项自动测试及 Windows 原生交互回归已通过；构建流程另验证安装包及更新清单。长历史组合压力测试与各平台日常试读仍会继续。

## 应用内更新

Windows Setup 安装版、Ubuntu deb/AppImage：打开“关于与更新”，检查更新，再点击“一键更新并重启”。新版入口位于顶部“应用设置”中；旧版仍使用原有“关于”入口。

Windows 便携版和 macOS 请从本发布页下载相应文件。更新保留论文、对话和笔记，正式版本不包含模拟回答。

详细架构与受控界面性能测量见[预览阶段记录](v1.3.0-preview.1.md)。其中约 70–72ms 的 p95 是界面响应测量，不是模型首字等待时间。
