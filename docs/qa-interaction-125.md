# v1.2.5 交互检查记录

2026-09-12，Windows Electron 桌面应用。先捕获原界面，再验证修改后的真实窗口；隔离资料库与合成 PDF，不修改日常阅读记录。问答流事件用于界面验证，真实模型延迟另见[专门记录](qa-reading-session-latency.md)。

## 检查结果

| 流程 | 发现与处理 | 验证 |
| --- | --- | --- |
| 标题联想 | 旧请求阻塞并丢弃新关键词；原备用检索不适合未输入完的标题 | 有界并发、仅保留最新待执行查询；前缀及拼写备用来源；旧响应不覆盖新词 |
| 搜索输入 | Enter 首次仅选中，需要再按一次 | 一次 Enter 打开首项；方向键、Escape、清空、中文选字分别检查 |
| 等待回答 | 空闲仍显示 THINKING | 空闲显示论文对话，生成中显示实际阶段 |
| 讨论切换 | 另一讨论回答时停止按钮含义不清 | 指明另一讨论正在回答，仍可写草稿；返回原讨论可停止 |
| 停止回答 | 中断请求失败后无法再次尝试 | 主辅窗口均可重试；旧请求的延迟错误不干扰下一轮 |
| 辅助浮窗 | 硬切换展开，已读内容折叠后误报新回答 | 局部高度过渡、按论文记录已读内容；折叠仍生成，主辅输出隔离 |
| 外观与可读性 | 浮窗层次及控件反馈较弱 | 局部背景模糊、边缘高光、短时过渡；正文与 PDF 不加模糊 |
| 外观偏好 | 需要随个人与系统设置简化效果 | 玻璃与减少动态效果开关、Escape 关闭、明暗主题及系统偏好检查 |
| 布局 | 需要确认新增效果不会让文字或操作越界 | 阅读/讨论/探索、资料库、笔记、关于窗口；1680×980 与 1180×768 检查 |

视觉参考：[Apple · Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。采用内容上方控件的半透明层次和短时反馈，避免让正文持续运动。玻璃也可完全关闭；高对比度与系统减少透明度有实色回退。

## 证据与边界

本机修改前后截图位于 `output/ui-review-125/`（开发验证产物，未加入发行包）。人工查看了明暗主题、界面效果菜单、辅助对话、资料库、笔记、关于与探索布局；检查了实际计算样式中的背景模糊，以及 PDF 画布未被滤镜处理。

`scripts/smoke-auxiliary-chat.mjs` 覆盖两路并发、交错输出、独立停止、失败重试、折叠、新旧会话与草稿恢复、切换论文。`scripts/smoke-appearance.mjs` 检查玻璃实际渲染、PDF 清晰、设置持久化、明暗主题及系统动态偏好；`scripts/smoke-paper-search.mjs` 检查联想异步顺序、键盘与中文输入、重试和打开论文。三项都纳入 Windows 发布流水线。

这次覆盖了主要阅读交互和已有单元回归，没有逐篇验证所有 PDF、所有网络故障或所有操作系统的辅助技术。探索页面验证到布局与加载状态，不据此宣称推荐结果质量提升；本版没有修改推荐算法。小样本延迟数据也不代表长篇、多图或复杂推理的固定速度。
