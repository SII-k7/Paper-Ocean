# v1.2.3 · 问答连接提速

修复部分网络环境下首问长时间等待的问题：旧版关闭 WebSocket 的参数在当前 Codex CLI 中未生效，连接失败后重试 5 次才回退 HTTP。现在新建和恢复的论文对话均直接使用 HTTP 流式连接。

保留 Luna max、Fast、现有论文上下文和对话历史。使用相同 20 页合成资料的本机测试中，首字由约 90 秒降至 27–35 秒，追问约 12–15 秒。实际耗时仍受网络、服务状态与思考复杂度影响。

125 项测试及类型检查、构建通过；真实 Codex 首问、追问及旧对话恢复验证通过。测试方法见 [问答延迟记录](https://github.com/SII-k7/Paper-Ocean/blob/v1.2.3/docs/qa-http-latency.md)。

## 更新方式

Windows Setup 安装版 v1.2.1 及以上，以及支持在线更新的 Ubuntu `.deb` / AppImage：进入「关于 → 检查更新 → 一键更新并重启」。更新会保存阅读记录。Windows 便携版和未签名 macOS 版本请手动下载安装包。

本次发布仅包含已验证的连接修复；提前建立会话、减少无关 MCP 启动等进一步优化尚未包含。
