# Paper Ocean v1.1.1

将应用标识统一为新的书页与星光图案：应用内 Logo、浏览器标签页、Windows 可执行文件、Ubuntu 应用菜单及 macOS 应用图标均使用同一张原始图片。保留现有主题色。

包含 v1.1.0 的 Ubuntu 支持与跨设备论文池；Windows / Ubuntu 经坚果云 WebDAV 的同步已经用户验证。论文池仅同步看过／问过的论文信息，不同步 PDF 或问答正文。

## 下载与更新

应用内「关于与更新 → 检查更新」可以发现本次正式版本，再点「查看发布页面」下载附件。当前采用手动更新，不会在后台自动替换应用。

- Windows：下载 `Paper-Ocean-1.1.1-win-x64.exe`，退出旧版后运行新版便携程序。可用新文件替换原启动文件，并更新快捷方式。
- Ubuntu：优先下载 `Paper-Ocean-1.1.1-linux-amd64.deb`，在下载目录执行 `sudo apt install ./Paper-Ocean-1.1.1-linux-amd64.deb`；另提供 x86_64 AppImage。
- macOS：提供 universal DMG，仍是未签名、未公证构建，本轮没有 macOS 实机验收。

继续使用相同系统账号与资料目录时，本机论文、对话及同步设置会保留。无需删除应用数据目录或重新创建坚果云论文池。附件提供 `SHA256SUMS.txt` 供校验。
