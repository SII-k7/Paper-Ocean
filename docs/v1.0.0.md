# v1.0.0 · 大版本迭代

2026-09-08。本次将论文阅读、固定论文集合讨论、原文证据笔记、论文发现和本地归档整合为完整研究工作台。版本号升级为 1.0.0；本次源码提交不等同于安装包发布。

## 这一版的主要变化

- 阅读连续性：PDF 页内位置、缩放、对话段落和草稿恢复；阅读／讨论／探索布局及可调整栏宽。
- 讨论与证据：固定论文集合、版本身份、逐页索引、按问题检索节选、原文页图与可回查的跨论文引用。
- 研究笔记：高亮坐标、多论文证据关联、回答转笔记、Markdown 与包含页图的 ZIP 导出。
- 发现与保存：标题模糊联想、在线检索备用路径、资料库管理、分来源推荐、下载进度及续传。
- 具身智能归档：已对话 PDF 自动保存到 `D:\paper`，四类主题与待分类，支持手动纠正及历史补齐。
- 可靠性：原件副本与内容校验、原子保存、损坏恢复、关闭保存、Web 并发修改冲突保护和随应用打包的 PDF 资源。
- 模型：固定 GPT-5.6 Luna · max，使用本机 Codex 登录状态。

## 本轮交互打磨

保留原有明暗主题和强调色。布局选择增加滑动指示，搜索下拉与对话框使用 180–240 ms 的短过渡；讨论／笔记切换淡入，常用提示按钮增加轻微悬停反馈。动效不作用于 PDF 正文或流式输出中的文字，系统开启“减少动态效果”时缩短至近乎即时。

搜索支持 `Ctrl/⌘ K` 聚焦并选中已有内容，一键清空后保留焦点；弹窗开启或输入法组合输入时，快捷键不会抢走焦点。键盘焦点样式统一，并修复搜索区域挤压顶栏操作按钮的问题。

## 验证

- 104 项自动测试通过，TypeScript 检查与生产构建通过。
- Windows Electron 隔离资料库实测：搜索快捷键、方向键选择、清空后的焦点、弹窗内快捷键保护、Escape 关闭、三种布局切换通过。
- 1440 × 900 与最小 1180 × 720 窗口、深浅主题截图检查；页面无横向溢出，渲染进程无未捕获异常。

- 用户已确认此前的中文输入和搜索／归档迭代体验。历史专项验证见同目录 `verification-*.md`；macOS 本轮未实机验收。

## 升级与数据

按 README 从源码运行或打包。Web 预览与桌面版的资料库相互独立，旧安装包不会自动加载新功能。归档 PDF 不包含对话和笔记备份；资料库、凭据、下载缓存及个人论文不随源码提交。
