# v1.2.5 · 模糊搜索、问答提速与玻璃交互

## 搜索论文

- 输入标题片段、词序变化、缺少字母或相邻字母拼错时，仍可下拉联想；本地标题支持 `Open VLA` / `OpenVLA` 等分词差异。
- 修复连续输入时新查询被旧请求挤掉的问题；旧结果不会覆盖最新关键词。
- Semantic Scholar 之外增加 OpenAlex 标题联想和拼写容错备用来源。网络失败可重试；Enter 或搜索按钮直接打开首项，方向键可选择其他项。
- 真实在线查询 `diffusion pol`、`difusion policy`、`openvl` 返回目标论文；模拟主服务限流后，真实备用来源仍找到 Diffusion Policy，并解析到 arXiv `2303.04137`。检索依赖公开服务，网络异常时本地匹配仍可用。

## 问答延迟

论文会话原先会读取无关的 Codex 跨项目记忆、技能和扩展。本版在论文会话内隔离这些额外准备工作，保留 Luna max Fast、原文、页图、历史和只读权限。

同一台 Windows 电脑、同一份 20 页合成论文：v1.2.4 当日基线首字 92.5 秒；本版两次冷启动首字 11.1 / 10.0 秒，追问 12.9 / 8.8 秒。原有会话恢复后首字 16.8 秒，下一问 8.3 秒。一次配置试验曾达到 5.4 秒追问，但不能保证所有论文几秒出字。完整方法、证据与限制见[延迟验证](qa-reading-session-latency.md)。

## 界面与操作

- 浮动工具栏、辅助对话、搜索建议和弹窗加入背景模糊、柔和高光、圆角与短时展开过渡，支持明暗主题。
- 顶部新增「界面效果」，可关闭玻璃质感、减少动态效果，并遵循系统相关设置。原文和回答正文保持清晰。
- 切换到另一讨论时说明原讨论仍在回答，避免误停止；停止失败可以重试。
- 辅助对话收起已读内容不再误报新回答；空闲标题显示「论文对话」，生成时显示实际阶段。

这套跨平台效果参考 Liquid Glass 的控件层次与动态反馈，属于应用自身实现。

## 验证与更新

132 项单元测试、类型检查、构建以及隔离 Electron 交互回归通过。覆盖搜索键盘与中文输入、主辅对话并发和恢复、明暗主题、玻璃开关、减少动态效果，以及较窄窗口布局。详细范围见[交互检查记录](qa-interaction-125.md)。

Windows Setup 安装版可在「关于 → 检查更新 → 一键更新并重启」安装。Windows 便携版和 macOS 请从发布页下载；Ubuntu 沿用应用内更新入口。
