# 下载、PDF 兼容性与真实证据验证

2026-09-07，全部使用隔离资料库。本轮未发布安装包，未替换用户原来的 PDF、笔记或会话。

## 下载

- Electron 和 Web 均接入流式下载、状态查询、取消与续传；主请求结束前的校验和原件准备与网络传输分开显示。
- 部分 PDF 写到 `.part`，记录 ETag／Last-Modified，续传使用 Range 与 If-Range。取消后立即继续，会先等旧文件句柄关闭。版本变化、服务器忽略 Range 时重新开始；超限、截断或不是完整 PDF 时不覆盖可用文件。
- Web 接口测试：收到 50 字节后暂停，立即续传从第 50 字节开始；请求继续使用 v7，只请求一次已缓存的元数据。另覆盖任务去重、取消早于任务注册、退出时等待资源清理。
- 真实界面：慢速隔离夹具传到 1,114,112 字节时暂停。关闭页面后重新打开，显示约 1.1/2.1 MB 与继续按钮；续传日志为 `Range: bytes=1114112-`，版本校验一致，完成后打开了 15 页 PDF。已有两篇论文的笔记和草稿保留。
- Windows PowerShell/.NET 通道使用真实 arXiv v7 PDF 验证过 206 响应、ETag、首块 `%PDF-` 和取消。界面慢速夹具明确标为合成测试元数据，不属于真实 arXiv 记录。

## PDF 资源与渲染

使用与应用相同的 `pdf-runtime.ts` 与资源地址，在浏览器实际渲染十页：标准字体、无文字层扫描、中文 CID 字体、90 度旋转、JPX、ICC，以及 Mozilla 的四个回归样例。默认解码与 `useWasm: false` 的 JS 回退均完成，各页文字数与非白像素数一致；逐页查看了渲染画面。

扫描页提取文字为 0，中文页为 33 字符，旋转页为 85 字符。扫描页与 JPX／ICC 页的数字、流程图、文字均可见。JBIG2 图形、JBIG2 TEXT 和 JPX 透明色块均可见。这里验证的是这些具体样例，不代表支持所有损坏或加密 PDF。

回归样例来源：[JBIG2 文件头](https://github.com/mozilla/pdf.js/blob/master/test/pdfs/jbig2_file_header.pdf)、[JBIG2 符号偏移](https://github.com/mozilla/pdf.js/blob/master/test/pdfs/jbig2_symbol_offset.pdf)、[JPX 透明度](https://github.com/mozilla/pdf.js/blob/master/test/pdfs/jpx_smaskindata.pdf)、[JPX 回归样例](https://github.com/mozilla/pdf.js/blob/master/test/pdfs/bug_jpx.pdf)。Poppler 另行渲染了自建扫描页、JPX 页和长文第 173 页作为核对；对 `bug_jpx.pdf` 返回了流格式错误，该样例不以 Poppler 为正确性基准。

索引页数不再标为“全文文本”，而是“已提取文字”；提示说明扫描和图表的视觉内容以本轮附图为准。保存层的缩放下限也统一为 25%，回归测试确认 30% 手动缩放可往返保存。

## 真实模型证据

通过实际界面、真实本机 Codex 登录和 GPT-5.6-Sol（low）完成三次问答；未使用模拟回答，测试 PDF 均为公开论文或标明合成的夹具。

| 场景 | 实际结果 |
| --- | --- |
| 无文字层的第 2 页扫描图 | 正确给出方法 73%、基线 61%、n=120、Sense→Plan→Act、仅室内试验；四项均引用正确论文的第 2 页 |
| 200 页合成长文，提问只给关键词 QUARTZ-173 | 检索到第 173 页，正确给出 84%、67%、240 次模拟试验和未评估室外迁移；明确说明仅覆盖 34/200 页 |
| 固定三篇资料，合计 221 页 | 正确区分 Attention 表 2 的 EN-DE BLEU 27.3／28.4、扫描夹具的 73%／61%／120、长文夹具的 84%／67%／240，引用各自第 8／2／173 页；没有把不同任务指标直接比较优劣 |

第三次显示文字节选 26/221 页和扫描夹具第 2 页图。点击实际模型的第 173 页引用后，打开对应长文，仍保持原三篇讨论，只渲染附近三个页画布。合成夹具中的数字不是科学结论。该验证是具体证据链的抽样验收，不是模型准确率评估；跨多篇自动找图、OCR 和一般长文检索召回率不在已验证能力之内。

## 更新与构建

“关于与更新”显示源码版本，只有手动点击检查才访问公开 GitHub Release API；不启动下载或安装。版本比较按数值处理，忽略无法比较的预发布标签，发布链接固定在本仓库下。限流、404 和网络失败不会显示“已经最新”。本次实际公开 latest 接口返回 404，保留为“未找到公开正式版本”；浏览器网络失败路径也已检查。

PDF、公式与 React 运行库分别构建，应用入口约 290 KB（此前约 1.17 MB）；运行库仍须加载，不宣称总下载体积减少。TypeScript 与生产构建通过，无大块体积警告。独立 Electron 窗口已载入该生产构建并正常显示 PDF。

## 桌面关闭

Playwright 驱动真实 Electron 窗口，输入草稿后立即关闭并重开，内容保留。随后发送真实论文问题，在流式回答有 155 个可见字符时关闭；磁盘保存 162 个原始 Markdown 字符，`pending=false`、`error=false`，重开后显示原回答且无永久加载状态。

验证发现中断片段需要明确标记，已增加“回答已停止，以上为已生成的部分内容”并区分失败提示。第二次真实流式验证在 152 个可见字符时关闭，保存 159 个原始字符、`interrupted=true`；重开后标记可见，没有永久加载状态。

2026-09-08 用户在原生窗口中确认中文输入没有问题。此前 Windows Computer Use 的截图接口报 `SetIsBorderRequired ... 0x80004002`；启用辅助功能树后可读，但控件输入又报坐标几何不可用／UIA CacheRequest 属性缺失。原生输入法的通过结论来自用户实机反馈，不来自脚本 composition 事件。
